# Screenshots

`tablet.png` and `phone.png` are generated from `e2e/deck.spec.ts` using synthetic
sessions (sample-api, sample-chat and codex-app). They contain no captured user
sessions. Rebuild the app, run `npm run test:e2e`, and review
`test-results/redesign-1280.png` and `test-results/redesign-390.png` before replacing
these files. Keep screenshots consistent with the tested UI.
